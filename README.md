## 📄 Project Summary

- **Target API Base URL:** `https://restful-booker.herokuapp.com`
- **Testing Scope:** Functional Testing, Integration Testing, CRUD Operations, Dynamic Data Handling, and Negative Scenarios.
- **Key Highlight:** Dynamic environment variable injection (e.g., automatically storing `token` and `bookingid` for chained requests).

---

## 🛠️ Tech Stack & Tools

- **Postman:** API collection design, pre-request scripts, and test assertions.
- **JavaScript (ES6):** Dynamic test scripts and response validation logic.
- **Newman CLI:** Command-line runner for executing Postman collections.
- **Newman Reporter HTML / HTML Extra:** Automated generation of detailed test reports.
